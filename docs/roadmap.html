05三个战略要点

所有提案背后的一贯逻辑。

① 四层执法，竞品最全链

落地后 reqbank 拥有 saguaro / agent-spec / cupcake 都没有的完整执法链。critic 核心已是纯函数（critic-prompt.mjs:139,163），只缺 CLI 入口。

PreToolUse deny（写前）
↓ PostToolUse critic（编辑后）
↓ Stop 终态门（收尾·对盘上 diff 裁决）
↓ gate（pre-commit / CI 同源）

② 考古入金，常驻银行

reversa 证明了「遗留系统→契约」的市场，但它是一次性框架。reqbank 做成 mine 首发 + reflect 持续回流，就是持续入金的银行。

mine 考古（git 历史/代码/存量计数）
↓ inbox 草稿 → 人审入库
↓ 钩子执法 → 违规/拦截落日志
↓ reflect 聚合回流 → 新条款建议 ↺

③ 两个免费卖点，锁死

cache-stable：确定性渲染（无时间戳、同输入同输出）天然不破 prompt cache——加 eval 断言防回归。

禁止类才可靠：obsidian-mind 实证「正向『去查文档』常被忽略，禁止类指令才可靠传播」——这既是 P1 分层注入（禁止类正文直注）的依据，也该写进 README 论证 Stop 硬拦截的必要性。
